# سنوي

تطبيق يحوّل الالتزامات السنوية الكبيرة إلى أقساط شهرية يدفعها المستخدم لنفسه،
فلا تفاجئه الدفعة عند موعدها.

المشكلة: العقل يحسب المصروف السنوي على أنه "ليس شهرياً"، فتبدو الميزانية مريحة
حتى تصل دفعة كبيرة دفعةً واحدة. الحل: كل التزام ÷ الشهور المتبقية لموعده = قسط
شهري يذهب إلى صندوق مخصص لذلك البند.

## التشغيل

```bash
npm install
npm run dev
```

### قاعدة كتابة الفحوص

`scripts/lib/checks.mjs` تحرس عائلةً واحدة من الأخطاء وقعنا فيها ثلاث مرات:
**فحصٌ يقول «تمام» وهو لم يفحص شيئاً.**

| الفخّ | لماذا يخدع | البديل |
|---|---|---|
| `head: true` | طلب HEAD بلا جسم، فلا تصل رسالة الخطأ ويبدو الجدول المفقود موجوداً | `select('*').limit(1)` |
| `rows.every(p)` | تُرجع `true` على مصفوفة فارغة | `allOf(rows, p)` |
| إدراجٌ يُتوقَّع فشله | يفشل أيضاً حين يغيب الجدول، فيمرّ الفحص لسببٍ آخر | `requireTables` أولاً |
| `data.length` | `data` تكون `null` مع الخطأ فينهار الفحص ويخفي ما بعده | `rowsOf(result, label, step)` |

الجامع بينها أن الفراغ يُقرأ نجاحاً. الوحدة تجعله فشلاً صريحاً.

## إضافة لغة

انسخ `src/lib/i18n/ar.ts`، ترجمه، وسجّله في `LOCALES` داخل
`src/lib/i18n/index.ts` مع اتجاهه. النوع `Translation` مشتق من الملف العربي،
فأي مفتاح ناقص يصير خطأ بناء لا نصاً مفقوداً يظهر بعد النشر.

قاعدة النصوص: لا نص عربي مكتوب داخل مكوّن — كله في ملف اللغة.
و`.num` توضع على الرقم وحده لا على سطر يخلط عربياً بأرقام.

التواريخ بالأرقام لا بأسماء الشهور: `8/2026` و`15/8/2026`. أسماء الشهور
العربية مذهبان — «أغسطس» و«آب» — وأيُّهما اخترتَ بدا غريباً لنصف القرّاء،
والأرقام تطابق ما تكتبه الفواتير والبنوك هنا. التنسيق كلّه من `format.ts`،
فلا `toLocaleDateString` في مكوّن.

`calc.ts` هو قلب التطبيق: كل تغيير في المنطق يبدأ منه ومن اختباراته في
`calc.test.ts`، لا من الواجهة.

## الحالة

المراحل الأربع مبنيّة: الالتزامات والقسط ووضع الجسر، لوحة الشهر والدخل
وتقويم الاثني عشر شهراً والتجديد بعد الدفع، تكلفة البند ومحاكي الادخار
والنسخة الاحتياطية، ثم تغليف أندرويد مع التنبيهات.

ثم المرحلة الخامسة: الثروة. كل ما سبقها يقيس ما يخرج، وهي وحدها تقيس ما
يتراكم — الأصول وصافي الثروة، وصندوق الطوارئ، ورقم الحرية وتاريخها، وترتيب
سداد الديون. شاشتها على `/wealth`، ومدخلها من آخر لوحة الشهر لا من تبويبٍ
ثامن: التنقّل السفلي محسوبٌ على سبعة، وثامنٌ يقصّ «الفواتير».

فُحصت المسارات على قاعدة بيانات حقيقية عبر `npm run check:uiflow`.

## النشر

الدفع على `main` هو النشر. `deploy.yml` يفحص مرة واحدة ثم ينشر الواجهة وخادم
MCP من نتيجة الفحص نفسها.

| التدفّق | متى | ماذا |
|---|---|---|
| `ci.yml` | كل PR، وقبل كل نشر | lint، أنواع وبناء، 278 اختباراً، فحص خادم MCP، بناء الدالّة |
| `deploy.yml` | دفع على `main` | يستدعي الفحص، ثم الواجهة والخادم بالتوازي |
| `pages.yml` · `mcp.yml` | يُستدعيان، أو يدوياً | النشر نفسه — يدوياً لإعادة نشرٍ بعد تبديل سرّ |
| `android.yml` | يدوياً أو على وسم `v*` | بناء APK |

**البوّابة قبل النشر لا بعده.** كان `npm run build` وحده يسبق نشر الواجهة —
يفحص الأنواع ولا يشغّل اختباراً واحداً — والنشر تلقائي. فما ينكسر كان يصل
الموقع في دقيقة بلا أن يوقفه شيء. الاختبارات وفحص الخادم كانت تعيش على أن
يتذكّرها من يدفع.

**والفحص لا يحتاج أسراراً:** يبني بقيمٍ وهمية لأن البناء يحقنها في الحزمة ولا
ينادي بها شيئاً. فيعمل على PR من نسخة مستنسخة حيث الأسرار غير متاحة أصلاً.

## بناء APK لأندرويد

الطريقة الموصى بها لا تحتاج Android SDK على جهازك:

1. من GitHub → **Actions** → **بناء APK** → **Run workflow**
2. حين ينتهي، نزّل `sanawi-apk` من صفحة التشغيل
3. افتح الملف على تلفونك واسمح بالتنصيب من مصدر غير معروف

قبل أول تشغيل، أضف المفتاحين في **Settings → Secrets and variables → Actions**:
`VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.

المفتاح العام يُحزم داخل التطبيق ولا ضرر في ذلك — الحماية كلها في سياسات RLS
لا في إخفائه. وضعُه في الأسرار يجعل تبديل المشروع تعديلَ إعداد لا تعديلَ كود.

### محلياً (يتطلب Android Studio)

```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```

الملف الناتج في `android/app/build/outputs/apk/debug/app-debug.apk`.

### تحديث التطبيق بلا تنصيب

الواجهة تُنشر على GitHub Pages مع كل دمج على `main`، والتطبيق يحمّلها من هناك
(`server.url` في `capacitor.config.ts`). فأي تغيير في الواجهة يصل بإعادة تحميل
من داخل التطبيق — زر «حدّث التطبيق» في شاشة الدخل — بلا تنصيب APK.

العنوان دومين مخصّص: `sanawi.kabblan.com` بسجل `CNAME` يشير إلى
`ams110.github.io`. ومع الدومين المخصّص يُخدَم الموقع من الجذر، فلا يُعيَّن
`VITE_BASE_PATH` في التدفّق.

الدومين يعيش في **إعدادات المستودع** (Settings → Pages → Custom domain)، لا في
ملف داخل المستودع: مع النشر عبر Actions لا يقرأ GitHub ملف `CNAME` من المنشور.
جُرِّب: وصل الملف إلى الموقع ولم يُربط الدومين. يبقى `public/CNAME` مرافقاً
للإعداد ووثيقةً لما هو الدومين، لا مصدراً له.

وGitHub يتحقّق من DNS الدومين دورياً **ويزيله إن فشل التحقّق**. حصل ذلك مرة:
كان السجل ممرَّراً عبر بروكسي Cloudflare فردّ `1016`، فأُزيل الدومين وسقط
الموقع بلا شهادة. السجل يجب أن يكون `DNS only` يشير إلى `ams110.github.io`.

`pages.yml` هو التدفّق الوحيد الذي ينشر على Pages. لا تضغط «Configure» في
بطاقات صفحة Pages: كل بطاقة تضيف تدفّقاً ينشر جذر المستودع فوق هذا البناء
ويُسقط الدومين معه.

يبقى بناء APK لازماً حين يتغيّر ما يمسّ النظام: إضافة أصلية، إذن، أيقونة.

**تفعيل يدويّ مرة واحدة:** Settings → Pages → Source → **GitHub Actions**.
بدونه يفشل النشر بـ `Get Pages site failed`. جرّبنا تفعيله من التدفّق نفسه
(`enablement: true`) فردّ `Resource not accessible by integration`: توكن Actions
لا يملك صلاحية إنشاء الموقع، إنما النشر إليه بعد إنشائه.

**المقابل:** التطبيق لا يفتح بلا إنترنت. وهو تنازل نظري: كل رقم فيه يأتي من
Supabase، فبلا إنترنت هو معطّل أصلاً محزوماً كان أو لا.

## الربط مع كلود (MCP)

`mcp/` خادم MCP يجعل التطبيق قابلاً للتشغيل بالكلام: «حطّيت 500 على تأمين
السيارة»، «كيف وضعي هذا الشهر؟»، «أي شهر جاي بيكون ثقيل؟». إحدى وعشرون أداة —
ثمانٍ للقراءة وثلاث عشرة للكتابة.

```bash
npm run build:mcp && npm run check:mcp
```

`check:mcp` تجربة كاملة بلا حساب ولا شبكة: Supabase مزيّف في الذاكرة، والتسع
عشرة أداة كلها تُنادى وتُقارَن أرقامها بحسابٍ يدوي.

يعمل بنقلين: رابطٌ بعيد لتطبيق كلود على التلفون، وstdio لعميل على جهاز.
وعلى الرابط البعيد يخدم **كل مستخدمي سنوي**: كلود يفتح صفحة دخول التطبيق،
وكلٌّ يدخل بحسابه فتنطبق سياسات RLS على صاحب الرمز وحده — بلا كلمة سرّ مخزّنة
ولا مفتاح خدمة.

وحساباته مستوردة من `src/lib/` لا معادةً كتابتها، فالقسط الذي يقوله كلود هو
الرقم المعروض في التطبيق.

التفاصيل وطريقة التسجيل عند كلود في [`mcp/README.md`](mcp/README.md).
